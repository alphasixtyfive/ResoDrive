ResoDrive 0.3.32 improves startup diagnostics and installation.

- Startup failures and unexpected crashes show a Windows error dialog with Copy details and saved local reports. Normal startup has no extra splash screen.
- One Setup includes standard and compatibility options, with clear explanations during installation. Updates remember your choice.
- Fresh installations use Program Files\ResoDrive. Updates can move older installations there while preserving settings, credentials and queued files.

Updating through 0.3.30's Update button keeps the old folder for that first update; the following update can move it automatically. Running the new Setup directly can move it now.

Reports stay on your PC and are never sent automatically.
