Explorer can finish copying a file before it reaches the server. ResoDrive 0.3.19 makes that remaining work easier to see: click the tray icon for a small popup with file progress, speed and queued files. Open ResoDrive or Settings from its compact footer. Right-click the icon for the usual commands.

You get a warning before disconnecting or exiting with unfinished uploads. If you choose to leave anyway, files already in the local cache stay there for the next connection. Updates wait until uploads can be verified as complete. Windows shutdown and automatic sleep protection also stay active while work is pending.

Drive order is now yours to arrange. Use the faint handle beside a drive, its small reorder menu, or Alt+Up and Alt+Down. A faint moving row and drop line show where the drive will go, and your order is saved. Status strips follow the rounded cards at different display scales.

This release also fixes recovery during exit and updates, improves large upload queues, and cleans up settings and process handling. It prevents a completed update from being reported as unfinished when the app reopens. Download syncs check for junctions in their destination before starting, so files cannot be redirected outside the chosen folder.

On a standard-user PC, an update started from an older version may still report that ResoDrive is running under another Windows account. Let uploads finish, choose **Exit** from the tray while signed in as the usual user, then run **ResoDrive-Setup.exe** and enter the administrator password.

Download **ResoDrive-Setup.exe** below, or check for updates in ResoDrive Settings.

Already installed 0.3.19? Run **ResoDrive-Setup.exe** again to get this revision. It replaces the earlier .19 installation and preserves your settings and cache. The same version number will not appear as a newer update in Settings.
